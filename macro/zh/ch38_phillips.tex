1958 年 11 月，伦敦经济学院的《经济学刊》（Economica）登出一篇 17 页的论文\cite{phillips1958}。题目叫《英国 1861—1957 年的失业与货币工资率变动率的关系》，作者菲利普斯（A. W. H. Phillips，1914—1975）在文末署的也是伦敦经济学院\cite{phillips1958,loc38}。他把将近一百年的工资涨跌与失业画在一起，用一条曲线把它们连了起来\cite{phillips1958}。
% 据: ph_source, ph_publisher, ph_title, ph_lse, loc_phillips, gnd_phillips, gnd_phillips_born, gnd_phillips_died

他原是工程师。伦敦科学博物馆集团的藏品页说他是“生在新西兰、由工程师转行的经济学家”\cite{smg38}。他 1946 年进伦敦经济学院读社会学与经济学，1949 年在那里做出一台叫 MONIAC 的模拟计算机\cite{smg38}。这台机器用来“以看得见的方式”演示货币在经济里的循环流动，大约造了 14 台\cite{smg38}。
% 据: smg_engineer, smg_lse46, smg_moniac49, smg_title, smg_circular, smg_fourteen

上一章的模型假定物价不动，只问收入、利率与汇率（\chref{ch:mundell}）。加拿大 1956—1961 年的失业率翻了一番还多，加拿大银行的行长科因（James Coyne，1910—2012）却担心通胀，政府与他为此闹翻（\chref{ch:mundell}）\cite{gnd38}。失业与通胀之间要不要取舍、取舍的代价多大，那个模型不回答。菲利普斯先问工资，英国的货币工资涨得多快，能不能用失业的多少与失业的变动来解释，进口价格急涨的年份除外\cite{phillips1958}。
% 据: gnd_coyne, gnd_coyne_born, gnd_coyne_died, ph_purpose

一年半以后，这条曲线到了美国。萨缪尔森（Paul Samuelson，1915—2009）与索洛（Robert Solow，1924—2023）把纵轴换成物价，画成一张“选择的菜单”\cite{samuelson1960,loc38,gnd38}。菜单上的每一个点，都是一种失业率配一种通胀率。通胀与失业真是一张可以点菜的菜单吗？
% 据: ss_issue, ss_menu, loc_samuelson, gnd_samuelson, gnd_samuelson_born, gnd_samuelson_died, gnd_solow, gnd_solow_born, gnd_solow_died

\section{当时的世界}\label{sec:phillips-world}

战后各国把就业写进了政策的目标。1962 年美国《总统经济报告》所附的顾问委员会年度报告回顾说，大萧条让美国与自由世界的大多数国家，为非自愿的失业承担起国家的责任\cite{erp1962}。报告写道：“失业从前几乎完全被看作个人自己的责任，现在则被承认是国家良心上的一项负担。”\cite{erp1962} 美国 1946 年的《就业法》要求总统向国会提交经济报告\cite{erp1962}。1962 年 1 月的报告说，复苏只把经济带到了“最大限度的生产、就业与购买力”这个目标的一部分路程\cite{erp1962}。英国 1948—1957 年的失业率，按 Feinstein 的估计在 1.0\% 到 1.6\% 之间\cite{boe2017}。菲利普斯的表 1 里，这十年的工资率每年涨 1.9\% 到 10.5\%\cite{phillips1958}。
% 据: erp_title, erp_cea, erp_depression, erp_conscience, erp_act, erp_maximum, ph_t1_1949, ph_t1_1951

失业这样低，物价却在涨，经济学家为原因争论不休。萨缪尔森与索洛的论文开头说，就像人们说将军总在打错的仗，经济学家也被指责在打错的通胀\cite{samuelson1960}。1946—1948 年美国物价上涨时，人们盯着集体谈判带来的一轮轮加薪\cite{samuelson1960}。他们说，大多数经济学家现在大概都同意，那次上涨主要是战时积累的流动资产与推迟了的需要拉起来的\cite{samuelson1960}。1955—1958 年物价又缓慢爬升，后期似乎是在产能日益过剩、劳动力市场松弛的情况下发生的\cite{samuelson1960}。
% 据: ss_wrongwar, ss_1946, ss_creep

一种看法归咎于需求过多，叫需求拉动；另一种归咎于工资与成本自己往上推，叫成本推动（本书的概括）。萨缪尔森与索洛不肯断言，物价若不坚决刹住就一定越涨越快\cite{samuelson1960}。他们把这留作悬而未决的问题，也许“爬行的通胀”只会引来爬行的通胀\cite{samuelson1960}。
% 据: ss_causations, ss_accelerate, ss_creeping

理论上，工资与物价怎样调整还空着。\chref{ch:islm}的 IS–LM 把货币工资当作给定（\secref{sec:islm-legacy}），\chref{ch:mundell}的模型假定物价不动。弗里德曼（Milton Friedman，1912—2006）1976 年在诺贝尔奖演讲里回顾了失业与通胀之间有稳定关系的假说\cite{friedman1976,loc38}。照他的说法，这个假说填补了凯恩斯（John Maynard Keynes，1883—1946）“理论结构的一个空缺”\cite{friedman1976,loc38}。它似乎正是凯恩斯自己说过还缺的那“一个方程”\cite{friedman1976}。
% 据: fr_lecture, fr_alacrity, fr_gap, loc_friedman, loc_keynes

货币在短期里有作用的想法，早就有人提过。休谟（David Hume，1711—1776）\cite{loc38}说过，在物价追上来以前，增加的货币刺激了产业（\secref{sec:bullion-hume}）。萨缪尔森与索洛在注里也提到休谟\cite{samuelson1960}。照他们的转述，物价上涨的时期似乎至少给经济一时的刺激，积极逐利的人占了便宜，代价落在比较被动的固定收入者、债权人与挣工资的人身上\cite{samuelson1960}。货币在短期内不中性、在长期内中性，长期的那一半是\chref{ch:naturalrate}的题目。
% 据: loc_hume, ss_hume

\section{一百年的工资与失业}\label{sec:phillips-curve}

菲利普斯从供求讲起。对一种商品或服务的需求相对供给越高，它的价格就涨得越快。他认为，这个道理似乎也该是决定货币工资率变动的因素之一，货币工资率就是“劳动服务的价格”\cite{phillips1958}。失业很少时，雇主竞相出价，工资会涨得很快。失业很多时，工人不愿接受低于通行水平的工资，工资只会很慢地下跌\cite{phillips1958}。所以他预期两者的关系“高度非线性”\cite{phillips1958}。
% 据: ph_demand, ph_price, ph_bid, ph_nonlinear

他还提出第二、第三个因素\cite{phillips1958}。第二个是失业的变动。失业水平相同，景气上升、失业减少的年份，雇主出价更急\cite{phillips1958}。第三个是零售物价的变动，它通过生活费用的调整影响工资。可他认为，这只在进口价格急涨、把零售物价推上去的时候才起作用\cite{phillips1958}。
% 据: ph_second, ph_third, ph_third2

他把 1861—1957 年分成三段分别处理\cite{phillips1958}。1861—1913 年的工资用 Phelps Brown 与 Sheila Hopkins 编的小时工资率指数，失业率用贸易部与劳工部根据工会报表算出的百分比\cite{phillips1958}。某一年的工资变动率，取前后两年指数之差的一半，再除以当年的指数\cite{phillips1958}。比如 1861 年的数，用的是 1860 年与 1862 年的指数\cite{phillips1958}。他解释说，指数量的是一年的平均水平，这种“一阶中心差分”是全年平均变动率最好的简单近似\cite{phillips1958}。
% 据: ph_periods, ph_pbh, ph_unemp, ph_central, ph_1861, ph_fn_central

他按失业率把这些年分成六组，每组取工资变动率与失业率的平均，画成六个十字（\tabref{tab:phillips-crosses}）\cite{phillips1958}。最低的一组失业在 2\% 及以下，最高的一组在 7\% 以上、11\% 及以下\cite{phillips1958}。每组里既有失业上升的年份，也有失业下降的年份。平均以后，失业变动的影响大体抵消，十字近似于失业保持不变时的工资变动率\cite{phillips1958}。
% 据: ph_crosses, ph_cancel

他选的函数是$y+a=bx^{c}$，$y$是工资变动率，$x$是失业率，都按百分数计\cite{phillips1958}。$b$与$c$用失业在 5\% 及以下的四个十字以最小二乘法估计，$a$靠反复试算，让曲线尽量靠近 5\% 到 11\% 之间的另两个十字\cite{phillips1958}。得到的曲线是
\begin{keyeq}
y+0.900=9.638\,x^{-1.394}.\label{eq:phillips-curve}
\end{keyeq}
取对数，就是$\log(y+0.900)=0.984-1.394\log x$\cite{phillips1958}。曲线说了两件事（本书的解读）。失业越少，工资涨得越快，而且越往左越陡。失业再多，$y$也只是趋近于$-0.9$，工资每年跌不到 1\%。
% 据: ph_form, ph_fit, ph_curve

各个周期的点围着曲线绕圈\cite{phillips1958}。景气上升、失业减少时，工资涨得比同一失业水平的平均快；景气下降时则慢\cite{phillips1958}。1862 年工资涨得特别多。他归因于这一年进口价格比上一年涨了 12.5\%，这与美国内战的爆发有关\cite{phillips1958}。1879—1886 年的周期几乎看不出关系\cite{phillips1958}。Phelps Brown 与 Hopkins 的指数以 Wood 早先的指数为基础，他改用 Bowley 的指数计算 1881—1886 年，通常的关系就出现了\cite{phillips1958}。
% 据: ph_loops, ph_1862, ph_fig4, ph_wood, ph_fig4a

有些年份的偏离，他从劳资关系里找原因\cite{phillips1958}。1893—1896 年景气回升，工资却涨得比平常慢。照他的读法，这是雇主格外抵制加薪，1897 年终于酿成劳资冲突\cite{phillips1958}。他说，翻一下劳资关系史就“证实了这个猜测”。那几年雇主联合会抵制工会八小时工作日的要求，机械工人联合会罢工，雇主以闭厂相对，一直到 1898 年 1 月\cite{phillips1958}。1912 年煤矿全面停工，工会的失业率 3 月一度升到 11.3\%。扣除罢工的影响，通常的关系就恢复了\cite{phillips1958}。
% 据: ph_1893, ph_suspicion, ph_eight, ph_1912, ph_1912adj

他还注意到，一个个周期的圈越来越窄\cite{phillips1958}。他给了两种可能的解释。一是早年的煤与钢铁业常用滑动工资表，工资跟着产品价格走，这两个行业在早年的指数里权重较大\cite{phillips1958}。二是集体谈判与仲裁、调解的推广，让工资对失业的反应有了时滞\cite{phillips1958}。
% 据: ph_narrow, ph_sliding, ph_timelag

1913—1948 年的工资，1921 年起用劳工部的小时工资率指数，失业率 1921—1945 年用劳工部的英国数字\cite{phillips1958}。1915—1918 年失业很少，工资涨得很快，生活费用也在急涨，按生活费用自动调整工资的协议变得普遍\cite{phillips1958}。这些调整是真的推高了工资，还是只替代了劳动需求旺盛本来就会带来的涨幅，他说并不清楚\cite{phillips1958}。1920 年的失业率是 2.6\%，1921 年升到 17.0\%，工资率跌了 22.2\%\cite{phillips1958}。照他的读法，失业急升只能解释一部分。生活费用跌了 12.8\%，大半是进口价格下跌的结果，“无疑”也是一个主要的因素\cite{phillips1958}。
% 据: ph_1921src, ph_1915, ph_1915b, ph_1921, ph_1921b

1922 年的失业率是 14.3\%，正在下降，工资率却跌了 19.1\%\cite{phillips1958}。他把大部分跌幅归因于这一年生活费用指数下跌 17.5\%\cite{phillips1958}。经过这一次，工会对自动调整的协议不那么热心了，这类协议随之减少\cite{phillips1958}。
% 据: ph_1922, ph_1922b, ph_agreements

为了按战前平价恢复金本位，英国决定压住需求、压低物价（\chref{ch:interwar}）。照菲利普斯的说法，这阻止了复苏，1925—1929 年的失业停在 9.7\% 到 12.5\% 之间\cite{phillips1958}。五年平均失业 10.94\%，工资平均每年变动$-0.60\%$\cite{phillips1958}。按 1861—1913 年的曲线，这个失业率对应$-0.56\%$\cite{phillips1958}。有人说压低物价的政策失败，是因为工人更顽强地抵制减薪。菲利普斯认为证据不支持这种说法\cite{phillips1958}。照他的说法，给定当时的失业，结果本可以根据战前的数据“相当准确地”预测出来\cite{phillips1958}。
% 据: ph_gold, ph_1925, ph_1925avg, ph_1925curve, ph_view, ph_predict

1935—1937 年工资的涨幅，也许比单靠就业的变动所能带来的大一些，一部分大概要归于生活费用的调整\cite{phillips1958}。1940 年与 1941 年的加薪，进口价格大概也起了作用；其余战时年份的点显示了经济管制的效果\cite{phillips1958}。1946 年的复员与 1947 年的煤炭危机让失业上升，1948 年又几乎正好回到拟合的关系上\cite{phillips1958}。
% 据: ph_1935, ph_war, ph_1948return

1948—1957 年的失业率是劳工部公布的大不列颠月度百分比的平均，工资用的是周工资率指数\cite{phillips1958}。1950 年的点很贴近曲线，1953—1957 年的点绕着曲线成一个窄圈，方向却与早年相反\cite{phillips1958}。他说，这样的圈可能来自工资调整的时滞。他把失业率滞后 7 个月，即用上一年 6 月到当年 5 月的平均，圈就消失了\cite{phillips1958}。1950 年与 1953—1957 年的点落在一条光滑的曲线上，与 1861—1913 年的曲线几乎完全重合\cite{phillips1958}。
% 据: ph_1948src, ph_1948wage, ph_reverse, ph_lag, ph_lagloop, ph_lagloop2

他的表 1 列出这十年工资率的实际变动，以及按滞后的失业率从曲线算出的部分，他称之为“需求拉动”\cite{phillips1958}。表里还有“成本推动”，即零售物价指数各月比上年同月涨幅的平均\cite{phillips1958}。\figref{fig:phillips_uk}(b) 画出了实际变动与需求拉动这两列。
% 据: ph_t1_def, ph_t1_cost, ph_t1_head

1948 年成本推动远大于需求拉动，工资的实际涨幅只略高于需求拉动\cite{phillips1958}。他认为，若不是工会配合 1948 年春开始的工资限制政策，涨幅大概会大得多。1949 年工资涨得比需求拉动少得多，他说这“无疑”是工资限制的结果\cite{phillips1958}。
% 据: ph_t1_1948, ph_1948cost, ph_restraint, ph_cripps48, ph_t1_1949, ph_1949less, ph_restraint49

1949 年 9 月英镑贬值，1950 年朝鲜战争爆发，1950 与 1951 年的进口价格涨得很快\cite{phillips1958}。1951 与 1952 年，成本推动与工资的实际涨幅都大大超过需求拉动，他称之为“成本通胀的明显例子”\cite{phillips1958}。1950 年与 1953—1957 年，实际涨幅几乎等于需求拉动，他说这些年“似乎是纯粹的需求通胀”\cite{phillips1958}。
% 据: ph_devaluation, ph_t1_1951, ph_t1_1952, ph_cost, ph_demand_infl, ph_t1_1950, ph_t1_1953, ph_t1_1954, ph_t1_1955, ph_t1_1956, ph_t1_1957

\figref{fig:phillips_uk}(a) 画的不是菲利普斯自己的序列。本书用英格兰银行《千年宏观数据》里的修订数据复算，工资用 Feinstein 的平均周工资收入，失业率用 Feinstein 按贸易部数据调整后的工会失业率\cite{boe2017}。周收入含加班等部分，与工资率不是一回事（本书的解读）。按菲利普斯的分组复算，六组的平均点仍顺着他的曲线往下走（本书的计算）。失业最低的一组 7 年，工资平均每年涨 4.0\%。最高的一组 8 年，平均每年跌 0.5\%（本书的计算）。各年的点却很散，与曲线平均差约 1.5 个百分点（本书的计算）。

\begin{example}{读菲利普斯的曲线}\label{ex:phillips-read}
用式~\eqref{eq:phillips-curve}。（1）失业率是 2\% 与 5\% 时，工资每年变动多少？（2）失业率多高时工资不变？（3）失业率从 5\% 降到 4\%，与从 2\% 降到 1\%，工资涨幅各多出多少？
\solution
（1）$2^{1.394}\approx2.628$，$y=9.638/2.628-0.9\approx2.77$，工资每年涨约 2.8\%。$5^{1.394}\approx9.43$，$y\approx1.02-0.9\approx0.12$，工资几乎不动。（2）令$y=0$，$x^{1.394}=9.638/0.9\approx10.71$，$x\approx5.48$，约 5.5\%，与菲利普斯说的 5.5\% 左右相合\cite{phillips1958}。（3）$y(4)\approx0.50$，$y(1)=9.638-0.9\approx8.74$。从 5\% 降到 4\%，涨幅多出约 0.37 个百分点；从 2\% 降到 1\%，多出约 5.97 个百分点。同样少 1 个百分点的失业，在失业很低的地方代价大得多，这就是“高度非线性”。
\end{example}

\section{从工资到物价}\label{sec:phillips-prices}

工资是成本，人们说的通胀却是物价。菲利普斯在论文开头举过一个例子\cite{phillips1958}。生产率每年提高 2\%，总需求同样增长，失业保持在 2\%\cite{phillips1958}。这时雇主竞价让工资每年涨 3\%，进口价格与其他要素的价格也每年涨 3\%\cite{phillips1958}。零售物价就每年平均约涨 1\%，即要素成本的涨幅减去生产率的增长\cite{phillips1958}。写成式子，设$\pi$是物价的变动率，$g$是生产率的增长率，
\begin{keyeq}
\pi\approx y-g.\label{eq:phillips-prices}
\end{keyeq}
这是教学用的近似，它假定工资以外的成本也按同样的速度涨，价格高出成本的比例不变（本书的解读）。弗里德曼概括当时的通行做法，也是考虑生产率的长期增长，把价格高出工资成本的部分看作“大致不变的加成”\cite{friedman1976}。
% 据: ph_example, ph_example2, ph_retail, fr_markup

在同一个例子里，他还算了进口价格要涨多快才会引起螺旋\cite{phillips1958}。进口占国民收入的五分之一时，进口价格每年要涨 13\% 以上，才会抵消生产率提高的作用，让零售物价涨得比 3\% 还快\cite{phillips1958}。这时生活费用的调整会把工资推得比劳动需求带来的更高，工资与物价就螺旋上升\cite{phillips1958}。他认为 1861—1913 年只有 1862 年的进口价格上涨，也许刚够引起一次温和的螺旋\cite{phillips1958}。
% 据: ph_fifth, ph_13, ph_spiral, ph_mild

结论部分先说，统计证据大体支持他的假说\cite{phillips1958}。不算进口价格急涨、引起工资与物价螺旋的年份，假定生产率每年提高 2\%，要让产品价格稳定，失业率要“略低于 2.5\%”\cite{phillips1958}。要让工资率稳定，失业率要在 5.5\% 左右\cite{phillips1958}。曲线在失业低的地方弯得厉害，所以失业保持在某个水平，工资的平均涨幅比失业围着这个水平上下波动时低\cite{phillips1958}。他最后说，这些结论“当然是初步的”\cite{phillips1958}。
% 据: ph_support, ph_stable, ph_wages5, ph_curvature, ph_tentative

\begin{example}{物价稳定要多少失业}\label{ex:phillips-stable}
用式~\eqref{eq:phillips-curve}与式~\eqref{eq:phillips-prices}，生产率每年提高 2\%，与菲利普斯的假定相同。（1）物价稳定时，失业率是多少？（2）失业率保持在 3\%，物价怎样变？（3）失业率一年 1\%、一年 5\%，交替出现，平均也是 3\%，工资的平均涨幅是多少？
\solution
（1）物价稳定要$y=g=2$，$x^{1.394}=9.638/2.9\approx3.32$，$x\approx2.37$，略低于 2.5\%。（2）$y(3)\approx1.18$，$\pi\approx1.18-2=-0.82$，物价每年约跌 0.8\%。（3）$y(1)\approx8.74$，$y(5)\approx0.12$，平均约 4.43\%，比失业稳定在 3\% 时的 1.18\% 高得多。菲利普斯的最后一条结论说的就是这个，曲线越往左越陡，失业忽高忽低，工资的平均涨幅就高（本书的计算）。
\end{example}
% 据: ph_example, ph_stable, ph_curvature

\begin{pitfall}[菲利普斯发现了通胀与失业的交替关系]
菲利普斯量的是货币工资率的变动，纵轴不是物价\cite{phillips1958}。物价是他从工资推出来的，要先扣掉生产率的增长。把纵轴换成物价的是萨缪尔森与索洛，他们同时提醒，这张菜单在更长的时期里不一定保持原样\cite{samuelson1960}。弗里德曼 1976 年画这条曲线时也说明，他跟着通行的做法，直接把失业与物价的变动连起来，“绕过了工资这一中间步骤”\cite{friedman1976}。菲利普斯自己则说，他的结论“当然是初步的”\cite{phillips1958}。
\end{pitfall}
% 据: ph_title, ss_translate, ss_longer, fr_shortcircuit, ph_tentative

\section{选择的菜单}\label{sec:phillips-menu}

萨缪尔森与索洛都在麻省理工学院\cite{samuelson1960}。他们的论文《反通胀政策的分析方面》登在 1960 年 5 月的《美国经济评论》上，那一期是美国经济学会第 72 届年会的论文集\cite{samuelson1960}。论文所在的那一组，题目是怎样达到并维持稳定的物价水平\cite{samuelson1960}。
% 据: ss_mit, ss_issue, ss_session

他们先概括菲利普斯的结论\cite{samuelson1960}。照他们的读法，失业 5\% 时货币工资就会稳定\cite{samuelson1960}。失业约 2.5\% 时，工资的涨幅能压到 2\% 到 3\% 的生产率增长\cite{samuelson1960}。这与原文的 5.5\% 和 2\% 略有出入（\secref{sec:phillips-prices}）。他们说，美国还没有人做过“同样仔细的研究”\cite{samuelson1960}。
% 据: ss_phillips5, ss_careful

他们自己画了美国的散点\cite{samuelson1960}。纵轴是制造业平均小时收入的年变动率，用的是 Rees 的数据，横轴是失业率\cite{samuelson1960}。1933—1941 年“自成一类”，失业极多，货币工资却在涨或者不跌\cite{samuelson1960}。他们说这可以归因于新政，1934 年工资涨了 20\%，一定反映了 NRA 的行业规章\cite{samuelson1960}。也可以说，到 1933 年许多失业已成为结构性的，与正常运转的劳动力市场隔开了\cite{samuelson1960}。
% 据: ss_rees, ss_suigeneris, ss_1934, ss_structural

20 世纪头十年与 1920 年代，失业 4\% 或 5\% 时制造业工资似乎就完全稳定\cite{samuelson1960}。1946 年以后的点相当一致，却与早年的明显不同\cite{samuelson1960}。失业率只在 1953 年的 2.5\% 到 1958 年的 6.2\% 之间\cite{samuelson1960}。他们判断，现在要失业“更像是 8\%”，货币工资才不涨。照他们的读法，这条关系在 1940 与 1950 年代略微但明显地向上移了\cite{samuelson1960}。
% 据: ss_early, ss_postwar, ss_range, ss_8pct, ss_shift

他们也比较了两国\cite{samuelson1960}。任何能让这条关系下移的东西，都会减少用压总需求来压工资与物价时“以失业支付的代价”\cite{samuelson1960}。一种可能是英国工会的领导层更“负责”，战后限制工资的政策在菲利普斯的数据里似乎也看得出来\cite{samuelson1960}。他们说还有别的解释。照他们的推测，英国地域紧凑，又更有意识地把工业迁往失业集中的地方，劳动力市场比美国完善\cite{samuelson1960}。他们由此认为，提高劳动力流动性的政策也有反通胀的作用\cite{samuelson1960}。
% 据: ss_compare, ss_price, ss_restraint, ss_compact, ss_mobility

他们把工资的图换算成物价的图，得出两个猜测\cite{samuelson1960}。要让工资只按 2.5\% 的生产率增长上涨，美国似乎要有 5\% 到 6\% 的平民劳动力失业\cite{samuelson1960}。他们说，在今后几年，这么多失业“似乎就是物价稳定的代价”\cite{samuelson1960}。要把失业压到 3\%，物价每年可能要涨 4\% 到 5\%\cite{samuelson1960}。这么多的物价上涨，似乎是今后几年高就业与高产出的必要代价\cite{samuelson1960}。
% 据: ss_translate, ss_translate2, ss_point1, ss_cost, ss_point2, ss_cost2

他们的图 2 把这些画成一条曲线，标出两个点\cite{samuelson1960}。A 点物价稳定，失业约 5.5\%；B 点失业 3\%，物价每年涨约 4.5\%\cite{samuelson1960}。图注说，这是不同程度的失业与物价稳定之间“选择的菜单”，大致据过去 25 年美国的数据估计\cite{samuelson1960}。他们预期，政治上的“拔河”会让美国在今后几年停在两点之间\cite{samuelson1960}。
% 据: ss_fig2, ss_pointA, ss_pointB, ss_menu, ss_tug

他们随即提醒，这些说的都是今后几年的短期\cite{samuelson1960}。以为这张菜单在更长的时期里会保持形状，照他们的说法就错了\cite{samuelson1960}。低压的经济也许会改变对工资的预期，让曲线下移\cite{samuelson1960}。也可能积累起越来越多的结构性失业，让菜单上移，需要越来越多的失业才能稳住物价\cite{samuelson1960}。两种可能都没有确凿的证据，他们说不下判断\cite{samuelson1960}。
% 据: ss_shortrun, ss_longer, ss_down, ss_up, ss_nojudge

他们提到，美国也许要 8\% 到 10\% 的失业才能稳住货币工资，又自问是不是“永远”如此\cite{samuelson1960}。这种关系也许在很大程度上取决于“记得的经验”\cite{samuelson1960}。他们猜想，经历过物价上涨、高就业与短而轻的衰退，货币工资就更难下降，通胀的倾向由此养成\cite{samuelson1960}。为什么菜单会漂移，是\chref{ch:naturalrate}的题目。
% 据: ss_810, ss_forever, ss_bias

他们也想到一场实验\cite{samuelson1960}。有意大幅压低需求，就有望分辨需求拉动与成本推动哪个对，他们自己预期结果在两者之间\cite{samuelson1960}。他们紧接着说，这是在轻率地谈论一场“巨大的实验”，它关系到社会福利\cite{samuelson1960}。相信成本推动的人会坚决反对，因为他们同样确信那会是一场惨败，带来许多“不必要的社会痛苦”\cite{samuelson1960}。
% 据: ss_experiment, ss_between, ss_vast, ss_pain

菜单上的每一个点，都在决定谁来付代价（本书的解读）。A 点的代价是失业，B 点的代价落在收入以货币固定的人身上。萨缪尔森与索洛列举通胀压低实际需求的机制，其中一条是对“固定收入”的挤压\cite{samuelson1960}。他们也写到，人们预期物价上涨，教师、领养老金的人等就会设法建立制度，保护实际收入不被侵蚀\cite{samuelson1960}。
% 据: ss_fixed, ss_teachers

失业也不平均落在每个人身上。按 1971 年《总统经济报告》的表 C-24，1961 年全体劳动者的失业率是 6.7\%\cite{erp1971}。16 到 19 岁的人是 16.8\%\cite{erp1971}。“黑人及其他种族”是 12.4\%，“与妻子同住的已婚男子”只有 4.6\%\cite{erp1971}。

\begin{example}{在两个点之间选}\label{ex:phillips-menu}
用萨缪尔森与索洛的两个点，A 点失业 5.5\%、物价不变，B 点失业 3\%、物价每年涨 4.5\%\cite{samuelson1960}。（1）从 A 移到 B，失业率与通胀率各变多少？（2）一位退休教师每年领 1,000 美元的养老金，数额不随物价调整。在 B 点过 5 年，这笔钱按开头的物价算值多少？（3）1961 年美国的劳动力约 7,160 万人\cite{erp1962}。失业率低 2.5 个百分点，大约多少人有了工作？
\solution
（1）失业率低 2.5 个百分点，通胀率高 4.5 个百分点。（2）$1{,}000/1.045^{5}\approx1{,}000/1.246\approx802$，约 802 美元，购买力少了约五分之一。在 A 点，这笔钱的购买力不变。（3）$7{,}160\times2.5\%\approx179$，约 179 万人。得到好处的是本来会失业的人，付出代价的是收入固定的人（本书的解读）。劳动力不变，是例子的简化。
\end{example}

\section{产出缺口与 4\% 的目标}\label{sec:phillips-gap}

\chref{ch:warfinance}里，凯恩斯 1940 年用计划的支出与产能之差判断通胀的压力（式~\eqref{eq:warfinance-gap}）。二十多年后，美国总统经济顾问委员会算的是另一种缺口，实际产出与充分就业时的潜在产出之差\cite{erp1962}。奥肯（Arthur Okun，生卒年未详）1962 年的论文问，充分就业时经济能生产多少\cite{okun1962}。他在注里说，这项研究主要是在顾问委员会任职时做的，文中的看法是他自己的，不一定代表委员会\cite{okun1962}。
% 据: erp_gap49, ok_question, ok_staff, ok_cfp, ok_author, ok_reprint

潜在产出先要定下充分就业指什么。照奥肯的定义，充分就业的目标是在更多的产出与更大的稳定之间求一个平衡点\cite{okun1962}。他说，有意思、也许出人意料的是，经济学家对 4\% 是合理目标的共识，似乎比对论证它所需的任何一步分析都多\cite{okun1962}。经济学家从来没有一个关于“可以容忍的物价表现”的明确标准\cite{okun1962}。他把 4\% 定为论文计算潜在产出所用的目标，说换一个失业率，方法不变，只有数字会变\cite{okun1962}。
% 据: ok_balance, ok_agreement, ok_criterion, ok_target

他的答案“简单而直接”\cite{okun1962}。战后平均而言，失业率在 4\% 以上每多 1 个百分点，实际国民生产总值就少约 3\%\cite{okun1962}。国民生产总值即 GNP，是一年生产的最终产品与劳务的市场价值。他用了三种方法\cite{okun1962}。第一种用季度的变动，1947 年第二季度到 1960 年第四季度共 55 个观测，失业率高 1 个百分点，产出少 3.3\%\cite{okun1962}。
% 据: ok_answer, ok_three, ok_first, ok_33

第二种试算潜在产出的几条路径，失业率对缺口的斜率在 0.28 到 0.38 之间\cite{okun1962}。第三种同时估计趋势与弹性，弹性在 0.35 到 0.40 之间\cite{okun1962}。他把这些系数“主观加权”平均，得到 3.2，写成
\begin{keyeq}
P=A\,[1+0.032\,(U-4)],\label{eq:phillips-okun}
\end{keyeq}
$P$是潜在产出，$A$是实际产出，$U$是失业率（\%）\cite{okun1962}。失业 4\% 时，潜在产出等于实际产出；失业 5\% 时，缺口是 GNP 的 3.2\%\cite{okun1962}。
% 据: ok_trial, ok_slopes, ok_method3, ok_elastic, ok_weighted, ok_rule, ok_five

他提醒，样本里的失业率只在约 3\% 到 7.5\% 之间，这个关系不该外推\cite{okun1962}。失业若是 1\% 或 15\%，他说没有理由指望 3.2 的系数还适用\cite{okun1962}。他举例说，把失业率降低 1.5 个百分点，就业的“分数”只是从 94.5 提到 96\cite{okun1962}。只这样看，降低失业的理由似乎不够有力；看缺口，才提醒决策者这种改善的回报很大\cite{okun1962}。
% 据: ok_range, ok_grade

1962 年 1 月，《总统经济报告》把 4\% 写成了目标\cite{erp1962}。肯尼迪（John F. Kennedy，1917—1963）在报告里写道：“战胜失业不是经济政策唯一的目的，但它一定是不可缺少的开端。”\cite{erp1962,loc38} 他说，战后有三分之二的月份，能工作、愿意工作、也在找工作的人当中有 4\% 以上找不到工作\cite{erp1962}。他接着说：“我们承担不起满足于任何规定的失业水平。但为了工作的需要，我们把 4\% 的失业率看作一个临时的目标。”\cite{erp1962} 他说这个目标 1963 年可以达到，复苏也必须不危及过去 4 年的物价稳定\cite{erp1962}。
% 据: erp_transmitted, erp_signature, erp_conquest, erp_twothirds, erp_target, erp_1963, erp_price, loc_kennedy

顾问委员会的年度报告在引言里写道：“非自愿的失业是经济浪费的一个标志，但失业根本的恶，在于它是对人的尊严的冒犯。”\cite{erp1962} 报告列出关心失业的三条理由，防止与解除经济困苦是人的义务，个人应当能自由选择怎样用自己的时间，闲置生产资源是经济的浪费\cite{erp1962}。它也承认零失业达不到，可行的临时目标要在就业、生产与国家政策的其他考虑之间求平衡\cite{erp1962}。报告提醒：“任何实际的失业目标都只是一时的折中，达到它绝不能成为松懈的理由，而应当激励人们去找出把失业率降得更低的办法。”\cite{erp1962}
% 据: erp_dignity, erp_reasons, erp_zero, erp_compromise

报告也说明了物价稳定为什么也是目标：“以经济现有的结构，以及物价与工资决定的过程，认真地把失业推到接近零，会造成很高的物价上涨率。”\cite{erp1962} 其结果是美国产品在世界市场上的竞争地位削弱，实际收入与财富被“任意地重新分配”；进一步通胀的预期若占了上风，后果还会更严重\cite{erp1962}。报告说，幸而两者的冲突只是部分的，稳定政策可以在两者之间求得平衡\cite{erp1962}。
% 据: erp_zero_infl, erp_redistribution, erp_partial

报告接着说明充分就业的含义。稳定政策的目标，是“消除总需求不足造成的失业，又不造成需求引起的通胀”\cite{erp1962}。接着它说明了这个目标的性质：“选定稳定政策的某个目标，并不使政策承诺一个不可更改的、与充分就业相应的失业率定义。情况可能改变失业率与物价水平对总需求数量的反应程度。因此，当前的经验必须是向导。”\cite{erp1962}
% 据: erp_cea, erp_fullemp, erp_commit

在当时的情况下，约 4\% 的失业率是“稳定政策一个合理而审慎的充分就业目标”\cite{erp1962}。报告还说：“4\% 的失业是一个不高的目标，但必须强调，这是一个应当只靠稳定政策就能达到的目标。”\cite{erp1962}
% 据: erp_reasonable, erp_modest

经济上一次处在 4\% 左右，是 1955 年 5 月到 1957 年 8 月，失业率在 3.9\% 到 4.4\% 之间\cite{erp1962}。那几年物价与工资的上涨削弱了一些美国产品在世界市场上的竞争力\cite{erp1962}。报告认为，这样的压力并不是经济在 4\% 附近运行时“持久的、系统的特征”，可也承认那几年的经验发人深省\cite{erp1962}。它说：“并没有一个确切的失业率，到了那里，总需求的扩张就突然不再影响就业，只影响一般物价水平。”\cite{erp1962}
% 据: erp_1955, erp_competitive, erp_notpermanent, erp_sobering, erp_noprecise

报告还算了缺口，并说“这类估计当然不可能精确”\cite{erp1962}。1961 年第一季度，实际 GNP 比充分就业时的产出少 510 亿美元，按 1961 年价格的年率计\cite{erp1962}。到第四季度，缺口缩小到约 280 亿美元，全年平均低于潜在产出 400 亿美元\cite{erp1962}。报告写道：“失业的水平是经济浪费的晴雨表。失业率每向 4\% 前进 1 个百分点，在战后的扩张时期意味着总产出约增加 3\%。”\cite{erp1962}
% 据: erp_precise, erp_gap49, erp_gap50, erp_3pct

报告也说了代价落在谁身上。用稳定政策去治摩擦性与结构性的失业，或者去消除自行定价、定工资带来的通胀压力，它说都不是无效的药，却是一剂“代价极高的药”\cite{erp1962}。为了消除物价上涨的一切风险而把总需求压得太紧，经济就可能远离充分就业\cite{erp1962}。报告写道：“公平会被牺牲，因为整个经济，尤其是失业者，会因少数个人与集团行使经济权力的方式而受罪。”\cite{erp1962}
% 据: erp_expensive, erp_restrict, erp_equity, erp_equity2

技术、消费者口味与工业的地理分布在变，总有工人因此丢掉工作，报告说这是“自由而进步的经济在增长中不可避免的一部分”\cite{erp1962}。它主张用职业培训、就业信息、帮助迁移、消除雇用中的歧视等政策缩小失业的人群\cite{erp1962}。报告说，没有这些政策，许多公民会成为“进步的牺牲品；他们被迫长期失业，这对谁都没有好处，却把不公正的惩罚加在任意挑出的少数人身上”\cite{erp1962}。还可以预期，受技术进步之害又看不到补偿的人会抵制进步\cite{erp1962}。
% 据: erp_displacement, erp_pool, erp_victims, erp_resistance

\begin{example}{1961 年的缺口}\label{ex:phillips-okun}
1961 年美国的失业率是 6.7\%，失业 480 万人，劳动力 7,160 万人\cite{erp1962}。（1）按式~\eqref{eq:phillips-okun}，潜在产出比实际产出高多少？与报告“约 8\%”的说法比较。（2）失业率若是 4\%，失业的人有多少？多出多少人有工作？占实际就业的多少？
\solution
（1）$0.032\times(6.7-4)=0.0864$，高约 8.6\%。报告用“约 3\%”的经验关系，$2.7\times3\%\approx8.1\%$，与“约 8\%”相合\cite{erp1962}。两者都只是近似。（2）$7{,}160\times4\%\approx286$万人，$480-286=194$万人，约 200 万人，与报告的数相合\cite{erp1962}。实际就业是$7{,}160-480=6{,}680$万人，$194/6{,}680\approx2.9\%$，即报告说的约 3\%\cite{erp1962}。就业只多 3\%，产出却多约 8\%。报告说，这是因为劳动力、工时与生产率也会跟着增加\cite{erp1962}。
\end{example}
% 据: erp_jobs, erp_labor, erp_magnified, erp_favorable, erp_table2, e71_c24_1961

\section{宏观计量模型}\label{sec:phillips-models}

菲利普斯的曲线只有一个方程。另一条路是把整个经济写成一组联立的方程。1936 年 9 月的牛津会议上，丁伯根（Jan Tinbergen，1903—1994）介绍了他用约 12 个方程描述战后美国经济周期的尝试（\chref{ch:islm}）\cite{oxford1937,loc38}。克莱因在萨缪尔森门下写完博士论文以后，进了芝加哥大学考尔斯委员会的计量经济学小组\cite{nobel1980bio}。照他自己的回忆，他在那里接到的任务，是“复兴”丁伯根早年为美国建计量模型的尝试\cite{nobel1980bio}。
% 据: loc_tinbergen, nbb_samuelson, nbb_reviving

1950 年，他出版了《美国的经济波动，1921—1941》，是考尔斯委员会的一本专著\cite{klein1950}。序言说，这本书出自 1944—1947 年考尔斯委员会里经济学家与数理统计学家的密切合作\cite{klein1950}。计量研究多靠为数不多的年度观测，他说这是他把这本书看作“初步的、试探性的”又一个重要原因\cite{klein1950}。书中的模型 I 是一个“简单的三方程体系”\cite{klein1950}。消费、投资与私人部门的工资总额各有一个方程，再加三个不含随机误差、也没有未知参数的定义式\cite{klein1950}。他得到的估计值是
\begin{equation}
\begin{aligned}
C&=16.78+0.02\,\Pi+0.23\,\Pi_{-1}+0.80\,(W_1+W_2),\\
I&=17.79+0.23\,\Pi+0.55\,\Pi_{-1}-0.15\,K_{-1},\\
W_1&=1.60+0.42\,X+0.16\,X_{-1}+0.13\,(t-1931),\\
X&\equiv Y+T-W_2,\qquad Y+T=C+I+G,\qquad Y=\Pi+W_1+W_2,\qquad \Delta K=I.
\end{aligned}\label{eq:phillips-klein}
\end{equation}
% 据: kl_title, kl_imprint, kl_cfm, kl_page, kl_preface, kl_tentative, kl_running, kl_definitional, kl_est_c, kl_est_i, kl_est_w, kl_identities

$C$是消费，$\Pi$是利润，$K$是资本存量，$I$是投资，即资本存量的变动，存货的净变动也算在里面\cite{klein1950}。$W_1$与$W_2$是私人部门与政府付的工资总额，$T$是企业税，下标$-1$指上一年\cite{klein1950}。$G$是政府与外国对产品的需求，外国的需求扣除了进口\cite{klein1950}。除时间$t$以外，所有变量都按 1934 年的美元计，单位是十亿美元\cite{klein1950}。$X$是本书为了简写记的，即$C+I+G-W_2$。工资方程里的时间趋势，照克莱因的说法，反映的是“劳工日益增强的谈判力量”\cite{klein1950}。
% 据: kl_investment, kl_inventories, kl_wagebill, kl_tax, kl_g, kl_g_fn, kl_units, kl_trend

模型里没有物价，也没有货币。克莱因说，这个简单模型“纯粹是一个实物体系”，货币的数量不起作用；他说这是一个简化的假定，书中还要检验关于货币市场的一些假说\cite{klein1950}。他的工资方程决定的是以 1934 年美元计的工资总额，菲利普斯的曲线讲的是货币工资率的变动，两者回答的问题不同（本书的解读）。
% 据: kl_real, kl_simplify

估计以前要先问能不能识别\cite{klein1950}。设想政府的变量都是零，体系里也没有滞后与趋势，几个方程的线性组合就会与投资方程长得一样\cite{klein1950}。克莱因说，那样就“无法区分”估出的是投资方程本身，还是几个方程的组合\cite{klein1950}。政府的外生变量、滞后与趋势，保证了这里的识别\cite{klein1950}。
% 据: kl_identify, kl_special, kl_nodistinguish, kl_insure

他用 1921—1941 年每一年的数据，以最大似然法估计，并假定各方程的扰动互不相关\cite{klein1950}。他说点估计看上去都合理，符号也都与理论的预期相符\cite{klein1950}。可这里“没有给出可靠性的量度”，只有点估计是不够的\cite{klein1950}。他也承认，这么小的体系的根本缺点是“太过加总”\cite{klein1950}。
% 据: kl_data, kl_ml, kl_rho, kl_reasonable, kl_reliability, kl_aggregative

\begin{compare}{统计关系与结构关系}{统计关系}{结构关系}
\cmprow{例子}{菲利普斯 1861—1913 年的曲线\cite{phillips1958}}{克莱因的模型 I，1921—1941 年\cite{klein1950}}
\cmprow{怎样得出}{按失业率分组取平均，再用最小二乘法拟合一条曲线\cite{phillips1958}}{先由理论定下每个方程里有哪些变量，再联立估计\cite{klein1950}}
\cmprow{先要问的}{曲线贴不贴近数据}{方程能不能识别，也就是能不能与其他方程的组合区分开\cite{klein1950}}
\cmprow{能回答}{两个变量一起怎样变}{政府支出变动以后，各个变量怎样变（\exref{ex:phillips-klein}）}
\cmprow{不能回答}{谁推动了谁}{政策规则变了以后，方程本身变不变（\chref{ch:ratex}）}
\cmpsum{统计关系说两样东西一起变，结构关系还要说清楚是哪一种行为让它们一起变。}
\end{compare}
% 据: ph_crosses, ph_fit, kl_running, kl_nodistinguish, kl_insure

\begin{example}{模型 I 的乘数与模拟}\label{ex:phillips-klein}
用式~\eqref{eq:phillips-klein}，$T$与$W_2$不变，政府对产品的需求$G$从某一年起永久增加 1（十亿 1934 年美元）。（1）当年的$X$增加多少？这叫冲击乘数。（2）资本存量不再变动时，$X$与$K$各增加多少？这叫长期乘数。（3）逐年算下去，$X$怎样走？
\solution
（1）当年的滞后项不变。$\Delta X$中工资占$0.42$，利润$\Delta\Pi=\Delta X-\Delta W_1=0.58\,\Delta X$。消费增加$0.02\times0.58+0.80\times0.42\approx0.348$倍的$\Delta X$，投资增加$0.23\times0.58\approx0.133$倍。$\Delta X=0.348\,\Delta X+0.133\,\Delta X+1$，$\Delta X=1/0.519\approx1.93$。（2）长期里滞后项与当年相等，净投资为零。工资占$0.42+0.16=0.58$，利润占$0.42$，消费增加$0.25\times0.42+0.80\times0.58\approx0.569$倍。$\Delta X=1/0.431\approx2.32$。投资方程给出$0.78\times0.42\times2.32=0.15\,\Delta K$，$\Delta K\approx5.07$。（3）利润上升，第二年投资更多，第 4 年$X$升到约 5.5。此后资本多了，投资下降，第 11 年回落到约 1.4，再慢慢趋近 2.32（\figref{fig:phillips_klein}）。这样逐年代入，就叫模拟（本书的计算）。
\end{example}

\fig{phillips_klein}{模型 I 的模拟（本书的计算）。政府对产品的需求从第 1 年起永久增加 1，单位是十亿 1934 年美元，其余外生变量不变，扰动取零。(a) $X=Y+T-W_2$的变动，虚线是冲击乘数 1.93 与长期乘数 2.32。(b) 资本存量$K$的变动，虚线是长期的 5.07。系数据克莱因（1950）。}{fig:phillips_klein}

模型 I 自己就会产生周期（本书的解读）。投资取决于利润，利润随产出走，资本积累起来又压低投资，产出于是一起一伏。瑞典皇家科学院 1980 年的新闻稿说，丁伯根主要分析景气与价格的运动\cite{nobel1980}。克莱因则首先想造一件工具，用来预测经济波动，研究经济政策的效果\cite{nobel1980}。
% 据: nb_tinbergen, nb_aim

后来的模型越来越大。新闻稿说，他与戈德伯格（Arthur Goldberger，1930—2009）合作的那个模型“最为著名”\cite{nobel1980,gnd38}。克莱因自述，戈德伯格是他在密歇根大学的学生，这个模型后来演变成一代又一代的密歇根模型\cite{nobel1980bio}。新闻稿说，到 1950 年代，他的美国模型已成为短期预测的成功工具\cite{nobel1980}。1980 年他获得诺贝尔经济学奖，理由是建立计量经济模型，并把它用于分析经济波动与经济政策\cite{nobel1980}。
% 据: nb_paper1950, nb_famous, gnd_goldberger, gnd_goldberger_born, gnd_goldberger_died, loc_goldberger, nbb_goldberger, nb_forecasts, nbf_motivation

\section{两个争论}\label{sec:phillips-debate}

\subsubsection{1960 年代的经济学家相信稳定的菜单吗}

第一个争论是 1960 年代的经济学家是否相信有一张稳定、可以利用的菜单。弗里德曼 1976 年回顾，这条关系当时被普遍理解为因果关系，给了决策者一种“稳定的交替”\cite{friedman1976}。经济学家忙着从各国的数据里估计它，又研究通胀与失业的得失，以便选出“正确的”交替\cite{friedman1976}。
% 据: fr_causal, fr_busied

照他的说法，这个假说被经济学界“欣然”接受，似乎为经济政策提供了一件可靠的工具\cite{friedman1976}。这一方的保留也来自他自己。他说，包括他在内的一些人从一开始就怀疑稳定的菲利普斯曲线，理由主要在理论上而不在经验上\cite{friedman1976}。只要经验看上去与假说相符，它就一直被接受，虽然总有少数异议者质疑\cite{friedman1976}。
% 据: fr_alacrity, fr_tool, fr_sceptical, fr_dissenters

另一方读的是原文。萨缪尔森与索洛说菜单只管今后几年，长期里会移动，往哪个方向移动他们不下判断（\secref{sec:phillips-menu}）。1962 年的报告说，失业率目标不是不可更改的定义，4\% 只是“临时的目标”\cite{erp1962}。可这一方也得承认，他们确实把它叫作菜单，并预期美国会停在两点之间；报告也确实按 4\% 算了缺口\cite{samuelson1960,erp1962}。至今没有定论。
% 据: ss_shortrun, ss_nojudge, erp_commit, erp_target, ss_menu, ss_tug, erp_gap49

\subsubsection{谁先发现了这条曲线}

第二个争论是谁先发现了这条曲线。费雪（Irving Fisher，1867—1947）1926 年 6 月在国际劳工组织的《国际劳工评论》上发表《失业与物价变动的统计关系》\cite{fisher1926,loc38}。他说，在 1915—1925 年这段重要的时期，美国美元价值的变动率与失业的相关系数“高达 90\%”\cite{fisher1926}。这么高的相关，他说只有用分布滞后的方法才求得出来，即物价变动的影响分摊到以后的若干个月\cite{fisher1926}。
% 据: fi_issue, fi_title, fi_author, fi_90, fi_distributed, fi_spread, loc_fisher

用固定的滞后，相关最高只有 79\%，是滞后 4 个月时的\cite{fisher1926}。这些数都来自 1915 年 9 月到 1924 年 12 月，那时物价大多在剧烈变动；物价变动不那么剧烈的时期，相关性也低一些\cite{fisher1926}。他也承认，这种关系“可以设想”不是因果关系，两者也许都出自第三种影响，物价变动也可能只是对生意好坏的预报\cite{fisher1926}。他说他不怀疑这两种看法都有几分道理\cite{fisher1926}。
% 据: fi_fixed, fi_violent, fi_causal, fi_third

费雪认为因果是从物价到就业，就业的起落“在很大程度上”是物价涨落的结果\cite{fisher1926}。他的机制是，物价上涨时企业的收入涨得和物价一样快，债券利息、租金、薪水与工资这些按合同固定的开支却涨得慢，利润于是增加\cite{fisher1926}。他也说，通胀即使帮工人找到了工作，也在抬高他的生活费用\cite{fisher1926}。
% 据: fi_effects, fi_contract, fi_costliving

另一方看两人量的是什么。菲利普斯量的是货币工资率，跨了将近一百年\cite{phillips1958}。费雪量的是物价，主要靠 1915—1924 年的月度数据\cite{fisher1926}。菲利普斯的因果从劳动的需求到工资，费雪的从物价到就业，方向正好相反（本书的解读）。可两人看到的相关是同一个方向，物价或工资涨得快的时候，失业少\cite{phillips1958,fisher1926}。至今没有定论。
% 据: ph_title, ph_price, fi_violent, fi_effects

\section{今天还剩什么}\label{sec:phillips-legacy}

\textbf{菜单的漂移。}弗里德曼说，战后同一失业水平对应的通胀率并不固定，往往随时间升高，高通胀与高失业并存的现象得了“滞胀”这个难听的名字\cite{friedman1976}。自然率假说与附加预期的菲利普斯曲线是\chref{ch:naturalrate}的题目，货币主义在\chref{ch:monetarism}，石油冲击与滞胀在\chref{ch:oil}。
% 据: fr_rise, fr_stagflation

\textbf{模型的命运。}克莱因的路后来通向布鲁金斯—社会科学研究会的大模型、沃顿的预测模型与连接各国模型的 LINK 项目\cite{nobel1980}。用历史数据估计的方程在政策规则改变以后还靠不靠得住，是卢卡斯批判的题目（\chref{ch:ratex}）。曲线后来有了新凯恩斯主义的版本（\chref{ch:newkeynesian}），2021—2023 年的通胀又让人重新讨论它（\chref{ch:inflation21}）。
% 据: nb_brookings, nb_wharton, nb_link

\textbf{缺口与目标。}奥肯的经验关系至今用来把失业与产出缺口连起来。1962 年的报告把 4\% 叫作临时的目标，说当前的经验必须是向导\cite{erp1962}。目标定在哪里，代价由谁来付，是每一次选择都要回答的问题（本书的解读）。
% 据: erp_target, erp_commit

\begin{takeaways}
\begin{itemize}
\item 菲利普斯（1958）用 1861—1913 年英国的工资率与工会失业率，按失业率分组取平均，拟合出$y+0.900=9.638\,x^{-1.394}$。失业越少，工资涨得越快，关系高度非线性，工资稳定的失业率约 5.5\%。
\item 物价的变动约等于工资的变动减去生产率的增长，这是教学用的近似。菲利普斯据此推出，生产率每年提高 2\% 时，物价稳定的失业率略低于 2.5\%，并说结论是初步的。
\item 萨缪尔森与索洛（1960）把曲线搬到美国、换成物价，画成“选择的菜单”，物价稳定要失业约 5.5\%，失业 3\% 要物价每年涨约 4.5\%。他们同时提醒，菜单在长期里会移动。
\item 奥肯（1962）估计，失业率在 4\% 以上每多 1 个百分点，产出约少 3\%。1962 年的《总统经济报告》把 4\% 当作临时的目标，并说失业的代价由整个经济、尤其是失业者承担。
\item 克莱因的模型 I 用三个行为方程与三个定义式描述 1921—1941 年的美国，冲击乘数约 1.93，长期乘数约 2.32，模拟出的路径一起一伏。模型里没有物价与货币。
\item 统计关系说两样东西一起变，结构关系要先解决识别。1960 年代的经济学家是否相信稳定的菜单，谁先发现了这条曲线，至今没有定论。
\end{itemize}
\end{takeaways}

\begin{selfcheck}
\begin{enumerate}
\item 用式~\eqref{eq:phillips-curve}，失业率是 3\% 时工资每年变动多少？是 8\% 时呢？
\item 若生产率每年提高 3\%，按式~\eqref{eq:phillips-prices}，物价稳定的失业率约是多少？比生产率提高 2\% 时高还是低？
\item 菲利普斯为什么要按失业率分组取平均，再去拟合曲线？
\item 按式~\eqref{eq:phillips-okun}，失业率是 5.5\% 时，缺口是多少？
\item 在\exref{ex:phillips-klein}里，若工资方程里当年产出的系数从 0.42 降到 0.30，冲击乘数变大还是变小？
\item 萨缪尔森与索洛的菜单，谁更喜欢 A 点，谁更喜欢 B 点？
\end{enumerate}
\end{selfcheck}

\begin{answers}
\item $3^{1.394}\approx4.62$，$y\approx2.08-0.9\approx1.18$，每年约涨 1.2\%。$8^{1.394}\approx18.15$，$y\approx0.53-0.9\approx-0.37$，每年约跌 0.4\%。
\item 物价稳定要$y=3$，$x^{1.394}=9.638/3.9\approx2.47$，$x\approx1.91$，约 1.9\%，比生产率提高 2\% 时的 2.37\% 低。生产率增长得快，工资可以涨得多而物价不涨。
\item 每组里有失业上升的年份，也有下降的年份，平均以后失业变动的影响大体抵消，十字近似于失业不变时的工资变动。
\item $0.032\times(5.5-4)=0.048$，潜在产出比实际产出高约 4.8\%。
\item 变小。工资分到的份额小了，利润分到的多了，而 1 元工资带来 0.80 元消费，1 元当年利润只带来$0.02+0.23=0.25$元支出。消费与投资增加$0.80\times0.30+0.25\times0.70=0.415$倍的$\Delta X$，冲击乘数是$1/0.585\approx1.71$，比 1.93 小。
\item 本来会失业的人更喜欢 B 点，收入以货币固定的人更喜欢 A 点。菜单本身不说谁对，选哪一点，就是选谁来付代价。
\end{answers}

回到 1958 年。菲利普斯把一百年的工资与失业画在一起，问的是劳动的需求怎样推动工资\cite{phillips1958}。两年以后，这条曲线成了菜单；再过两年，失业 4\% 成了美国的临时目标\cite{samuelson1960,erp1962}。克莱因的模型 I 里，三个行为方程有两个是消费与投资，乘数与周期都从它们来。消费方程为什么这样写，投资又由什么决定，模型本身不回答。政府一次性发钱，人们会花掉多少？企业凭什么决定投资？
