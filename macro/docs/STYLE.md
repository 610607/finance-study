# 写作与绘图规范（第一卷，中文母本）

写任何一章之前先读本文件、`docs/PLAN.md` 中该章的条目，以及 `preamble.tex` 里各种框的定义。第一章样章写定后，这里会补上从样章总结出的写法。

## 1. 目标：让人学会，而不是罗列

- **问题先行。** 每章以导引框里的核心问题开始（桩文件已写好），第一节交代“当时的世界”：事件、数据、人们当时怎样理解它。每一节先说为什么需要它。
- **概念随用随引。** 不要一上来列定义。顺序是：情景 → 直觉或图 → 推导 → 带数字的例题 → 会出什么错。
- **历史与理论交替。** 理论是为回答当时的问题而生的：先讲问题，再讲理论；理论讲完，回到数据检验它，再看后来的人怎样修正它。
- **对照是一等公民。** 两个概念容易混淆或彼此类比时，用 `compare` 框；每章 2—4 个，3—6 行，以 `\cmpsum{}` 一句话收尾。
- **每章至少一个英美以外的案例**，用 `case` 框。
- **集中处理保留意见。** 重要的限定条件都要写，但集中写在一个 `pitfall` 框、一节末尾的“适用范围”句或一个 `deeper` 框里，不要每句话都打折扣。
- **讲清每一步的理由。** 每个推导步骤给出一句话的原因；先用平实的话，再用符号；数字带单位与年份。
- **深度分层。** 主线按本科高年级水平推导；研究生水平的推导（动态优化、对数线性化、求解方法）放进 `deeper` 框，初读可跳过。
- 每章最后一句把读者交给下一章的问题。

## 2. 章节骨架（`zh/chNN_slug.tex`）

```latex
\chapter{标题}\label{ch:slug}
\begin{chapterguide} ... \end{chapterguide}      % 桩文件已有；修改时同步 PLAN.md
\section{当时的世界}\label{sec:slug-world}       % 事件、数据与当时的理解
\section{……}                                     % 理论的回答：直觉 → 推导
\begin{intuition}[可选小标题] ... \end{intuition}                     % 1—3 个
\begin{keyeq} ... \label{eq:...}\end{keyeq}                            % 最重要的 2—5 个公式
\begin{example}{标题}\label{ex:...} 题目 \solution 解答 \end{example}  % 至少 1 个
\begin{case}{地点 · 年代 · 标题} ... \end{case}                        % 至少 1 个英美以外
\begin{compare}{标题}{A 列}{B 列}
\cmprow{方面}{A}{B}
\cmpsum{一句话区分}
\end{compare}
\begin{pitfall}[误区的说法] ... \end{pitfall}
\begin{deeper}[可选标题] ... \end{deeper}
\fig{figname}{图注}{fig:figname}
\section{数据检验与反例}
\section{今天还剩什么}\label{sec:slug-legacy}     % 被吸收、被修正、被推翻的部分；与 2026 年争论的联系
\begin{takeaways}\begin{itemize}\item ...\end{itemize}\end{takeaways}   % 4—6 条
\begin{selfcheck}\begin{enumerate}\item ...\end{enumerate}\end{selfcheck} % 4—7 题
\begin{answers}\item ...\end{answers}                                  % 每题一条
```

- 写正文时删去桩文件末尾的 `\chapterstub`；`validate_source.py` 用它统计还剩多少章没写。
- `\section` 编号并进入目录；`\subsection` 不编号，少用；`\subsubsection` 为段首小标题。
- 不用 `\clearpage`、`\newpage` 或手动垂直间距。
- 表格：`table` 浮动体，`\caption` 在上，`tabularx` 加 `booktabs`，列类型 `Y`。
- 数据图或数据表下用 `\datasource{来源，序列，下载日期}` 注明来源。

## 3. 语言与记号

- 简体中文，讲解语气（可以用“我们”），避免翻译腔，一段一个意思。
- 关键术语首次出现时加粗，可附英文：`\textbf{自然利率}（natural rate of interest）`。
- 外国人名首次出现用通行中译名加原名与生卒年，例如 维克塞尔（Knut Wicksell, 1851—1926）；之后只用中译名。没有通行译名的用原名。文献引用处用原名，例如 Kydland \& Prescott (1977)。
- 中国古代人名、年号首次出现注公元年份，例如 天圣元年（1023）。
- 全角中文标点；数学放在 `$...$` 里；数字与单位之间用 `\,`：`$2\,\%$` 或 “2%”，全书统一用后者；区分“百分点”与“百分比”。
- 年份范围用“—”：1929—1933 年。
- 符号以附录 B 为准（`$Y$`、`$\pi$`、`$i$`、`$r$`、`$r^{*}$`、`$g$`、`$b$`、`$s$`、`$e$`、`$\E_t$`）；汇率 $e$ 一律定义为一单位外币折合多少本币。
- 交叉引用只用 `\chref{}`、`\secref{}`、`\figref{}`、`\tabref{}`、`\exref{}`、`\eqref{}`、`\appref{}`；跨章引用的标签必须登记在 `PLAN.md` 的 Label registry 中。
- 涉及 2024 年以后的事实写明时点，例如“截至 2026 年 10 月”。

## 4. 文献

- 只引用 `references_zh.tex` 里已有的条目。新条目必须真实、可核实：作者、年份、题名、出版者或期刊、卷期页码，有 DOI 或稳定链接的给出链接。`PLAN.md` 中的“候选文献”是起点，不是已核实的书目。
- 核实不了的文献不引用；确需引用时，在最终报告里给出完整条目，交给编者核实。
- 思想史的论断：引原始文献，并参照 De Vroey (2016) 与 Snowdon & Vane (2005)。
- 有争议的作品（例如 Graeber 2011）可以作为一种观点引用，并写明它的争议所在。
- 中文古籍注明篇名；引用译本时注明译本。

## 5. 数字与数据

- 正文里的每个数字，要么来自 `data/snapshots/` 中带元数据的快照（`data/README.md`），要么由 `checks/check_chNN.py` 从写明的教学输入算出；两种情况都要在脚本里断言（`checks/common.quoted`）。
- 不编造统计、参数或经验规则。教学输入在文中声明一次即可。
- 前现代与计划经济的数据多为重建估计：写出估计者与方法，给出不确定性的范围；有不同估计时并列。
- 计划经济与威权政权的官方统计，与外部重建估计并列，并说明差异来源（第 81 章）。

## 6. 模型与方法

作者的要求：**不自写算法或自创方法，用开源库；方法要能追溯到来源；任何改动写明理由。**

- 数值与数据：NumPy、SciPy、pandas；时间序列与计量（滤波、VAR、回归）：statsmodels。
- 动态模型：QuantEcon（`quantecon` Python 包）用于基础动态规划与马尔可夫过程；HANK 等异质主体模型用 Auclert 等人的 sequence-jacobian 工具包（github.com/shade-econ/sequence-jacobian）；需要 Dynare（dynare.org，可在 Octave 中运行）时说明原因。写到相应章节时核实版本与接口，在 `requirements.txt` 中固定版本。
- 原作者公开了代码的估计（例如纽约联储的 Holston–Laubach–Williams $r^{*}$ 代码），优先使用原代码或其公开结果，而不是自己重写。
- 简单的教学模型（凯恩斯交叉、IS–LM、三方程模型等）是解析的或线性的，可以直接用 NumPy 写出方程求解；这不算自创方法，但要在注释里指明方程出自哪一章、哪个公式。

## 7. 插图

- 每章一个模块 `figsrc/fig_chNN.py`；每幅图是一个用 `@figure("name")` 修饰、返回 Figure 的函数。构建与查看：`MACRO_LANG=zh python3 figsrc/build.py name1 name2`，输出 `figures_zh/name.{pdf,png,svg}`。
- **所有文字用 `T("中文", "English")`**，为英文版预留。
- 颜色语义（不得偏离）：产出与实体经济 `OUTPUT` 绿；价格与通胀 `PRICE` 朱红；货币与利率 `MONEY` 蓝；财政与政府 `FISCAL` 紫；对外部门与汇率 `EXTERNAL` 橙；制度、数据与其他 `INSTIT` 暖灰。案例相关的强调色 `CASE`。
- 尺寸：宽 `FIG_W`（6.0 英寸，等于正文宽度），高度尽量小（典型 2.2—3.6 英寸）。
- 时间序列：横轴为年份；长期序列用对数纵轴并注明；危机或衰退期用 `shade_periods()` 浅灰阴影，并在图注里说明阴影的来源（如 NBER 衰退日期）。
- 数据图读取与检查脚本相同的快照；模型图从 `checks/check_chNN.py` 导入函数，保证正文、图与检查同出一源。
- 图注第一句告诉读者看什么，然后说明图中内容，最后简短交代数据来源或教学性质。
- 构建后用 Read 工具逐张打开 PNG，修正重叠、裁切、过小的字与错误的方向。

## 8. 争议与敏感题材

- 有争议的问题（现代货币理论、财政主导、$r^{*}$、产业政策、休克疗法与渐进改革、紧缩等）：给出各方最强的论证与证据，标明证据的强弱，不替读者下结论。
- 纳粹德国、苏联集体化与饥荒、大跃进等：做经济分析的同时写明人的代价与政治性质；不把“短期见效”写成对政策的肯定。
- 涉及仍在进行的政策争论时，陈述而不评判在任官员或政党。

## 9. 术语（全书统一）

国内生产总值（GDP）；国民总收入（GNI）；名义 / 实际；价格水平；通胀率；通缩；滞胀；恶性通胀；货币存量；基础货币；广义货币；准备金；政策利率；中性利率（$r^{*}$）；自然利率（维克塞尔意义上）；自然失业率；菲利普斯曲线；乘数；节俭悖论；流动性偏好；流动性陷阱；零利率下限；量化宽松；前瞻指引；收益率曲线控制；收益率曲线；期限溢价；到期收益率；盈亏平衡通胀率；经常账户；资本和金融账户；国际投资头寸；外汇储备；购买力平价；利率平价；不可能三角；固定汇率 / 浮动汇率；货币局；美元化；铸币税；通胀税；货币主导 / 财政主导；基本盈余；政府预算约束；李嘉图等价；适应性预期 / 理性预期；卢卡斯批判；时间不一致；可信度；牺牲率；最后贷款人；挤兑；影子银行；金融加速器；宏观审慎；资产负债表衰退；短缺经济；软预算约束；被压抑的通胀；货币过剩；价格双轨制；休克疗法；渐进改革；部门余额；存量—流量一致模型；现代货币理论（MMT）；财政价格理论（FTPL）；货币等级；原罪（货币错配意义上）。

## 10. 检查一章

- `python3 checks/check_chNN.py`：本章所有数字的断言都通过。
- `python3 tools/check_chapter.py zh/chNN_slug.tex`：没有 LaTeX 错误、溢出的行、未定义的引用或文献、缺字，页边没有墨迹；再看它生成的缩略图 `build/check_chNN_slug/sheet_*.png`。
- `python3 validate_source.py`：结构、标签、引用、文献、插图、数据快照与检查脚本一致。
- 最后 `python3 build.py` 编译全卷，或 `python3 build.py --book N` 只编所在分册。
