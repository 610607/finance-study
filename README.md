# finance-study · 金融学习丛书

A self-study series in economics and finance, written as question-driven textbooks in the form of [electromagnetics-study](https://github.com/610607/electromagnetics-study): every chapter opens with a concrete question, compares easily confused concepts side by side, and every number in the text can be recomputed from data snapshots and check scripts in the repository.

以问题为线索的经济与金融自学丛书，形式参照 [electromagnetics-study](https://github.com/610607/electromagnetics-study)：每章从一个具体问题出发，把容易混淆的概念并排对照，正文中的每个数字都能由仓库里的数据快照与检查脚本复算。
